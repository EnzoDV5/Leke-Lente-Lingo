# Lente Book 🌱

The living dictionary for **Lentedag 2026**. Part of the *Leke Lente Lingo* campaign
(PP 410, Group 3). At the festival, boards and posters carry South African moments
that have no Afrikaans word yet ,  the crowd invents one, votes, steals & improves,
and every word is kept forever in Lente Book.

## Stack
- **React + TypeScript** (Vite)
- **Tailwind CSS v4** (CSS-first tokens, no config file)
- **Firebase** ,  Firestore (words/votes) + Auth

## Getting started
```bash
npm install
npm run dev
```

## Structure
Mobile-first. Design tokens live in `src/styles/`; screens live in `src/features/`;
shared UI in `src/components/`. See folder tree below.

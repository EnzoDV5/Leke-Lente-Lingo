# Leke-Lente-Lingo
The living dictionary for Lentedag 2026. Part of the *Leke Lente Lingo* campaign (PP 410, Group 3). At the festival, boards and posters carry South African moments that have no Afrikaans word yet, the crowd invents one, votes, steals &amp; improves, and every word is kept forever in Lente Book.
